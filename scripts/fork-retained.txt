# Fork-retained regressions.
#
# This repo is a fork of gastownhall/gascity. Merging upstream has silently
# dropped fork-added regression tests (the test stops existing) and small
# build-config pins (a BUILD data/env entry reverts to upstream's). This file
# lists what the fork must keep; scripts/fork_retained_test.go
# (TestForkRetainedRegressionCoverage in //scripts:scripts_test) checks it.
#
# Grammar, one directive per line ('#' starts a comment, blank lines ignored):
#   test <package dir> <TestName>
#       Some *_test.go in <package dir> must define func <TestName>(, and that
#       file must be in a go_test srcs of the directory's BUILD.bazel.
#   contains <repo-relative file> <literal, to end of line>
#       The file must contain the literal (spaces allowed).
#
# Each entry is preceded by the fork commit that added it, so a red run can be
# repaired by restoring that change rather than deleting the line. Adding a
# fork test means adding its own "test" entry here. Deleting an entry retires
# the guard for whatever it covers: restore the lost test or pin instead.
#
# Regenerate the test list by extracting the `+func Test...(` lines a
# `git log --no-merges -p upstream/main..origin/main -- '*_test.go'` adds, then
# keeping only the functions that still exist on the branch.
